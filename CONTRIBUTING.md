# Contributing to OpenReactor

Thanks for helping build OpenReactor.

## Ground rules

- Keep changes small and focused.
- Align with `PRODUCT_SPEC.md` and project constitution.
- Include tests/docs for behavior changes where practical.
- Do not introduce illegal, harmful, deceptive, or privacy-invasive functionality.

## Pull Requests

1. Open an issue first for non-trivial changes.
2. Submit PR with clear summary and rationale.
3. Ensure checks pass.
4. Be responsive to review feedback.

## Licensing of contributions

By contributing, you agree that your contribution is licensed under the project’s open-source license (AGPL-3.0-or-later), and you agree to the contributor terms in `CLA.md`.

If you are contributing on behalf of a company, you represent that you have authority to do so.

## Code of conduct

Be respectful and constructive. Harassment and abuse are not tolerated.
