# Roadmap

## Now

Launch the thinnest loop that allows OpenReactor to begin collecting work:

1. Public website with request form
2. Request validation and normalization
3. GitHub issue creation
4. Public queue view of recent requests

## Next

Once the intake loop is live and stable:

1. Add maintainer triage states and labels
2. Add agent-readable issue templates and planning docs
3. Add implementation automation for accepted requests

## Later

Only after repeated live usage validates the workflow:

1. Add persistent internal state beyond GitHub
2. Add queue workers and scheduled reconciliation
3. Add deployment status tracking and transparency metrics
